# Historical method contracts

Files in this directory preserve superseded method contracts for archive and
review purposes. The active method factory discovers only
`validation/methods/*.manifest.json`; it does not discover this directory.

The MICOM/permutation-MGA v2 contract is retained because existing v2 project
archives remain readable. It must not be moved back into the active manifest
directory or used as current promotion evidence. The stable capability ID is
owned by the active v4 manifest, whose permutation plan fixes the v2 A/B-swap
coupling defect without relabelling historical output.

The CB-SEM bootstrap v2 contract likewise preserves the historical schema-3,
percentile-only identity for archive readers. Current Registry V2 qualification
for `qpls3.cbsem.bootstrap` is owned only by the active Recipe-v4 exact-CFA
`cbsem_exact_case_bootstrap_v1` manifest.

The prospective-power v1 contract is retained as the preregistered,
failed-calibration historical record and for archive readers. It is not an
active promotion candidate. Current qualification for
`qpls3.pls.sample_size_power` is owned only by the active
`pls_sample_size_power_v2` manifest; v1 results are never relabelled as v2.
