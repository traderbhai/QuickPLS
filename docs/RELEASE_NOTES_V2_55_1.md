# QuickPLS 2.55.1 Release Notes

QuickPLS 2.55.1 adds the full Corporate Reputation comparison project to the
built-in sample gallery. Opening the sample loads the prepared 344-case data,
the eight-construct mixed formative/reflective PLS-SEM model, all 13 structural
paths, and a completed QuickPLS result.

The bundled benchmark checks 48 displayed values—outer weights, loadings, path
coefficients, and R-squared values—against the supplied SmartPLS reference at
three decimal places. This is a bounded display-parity check, not a claim of
bitwise equivalence with SmartPLS or endorsement by SmartPLS GmbH.

The application, installer, portable desktop executable, and CLI share version
2.55.1. Local release files are unsigned; verify their SHA-256 hashes before
distribution or installation.
