# QuickPLS 2.14.0

QuickPLS 2.14.0 adds a real-dataset feedback triage layer for the QuickPLS 2.x frontend program.

## Added

- An anonymized feedback triage template for private SEM dataset reviews.
- A generated v2.14 triage backlog artifact under `validation/results/`.
- Smoke and audit checks for the real-dataset feedback intake process.
- Updated active milestone tracking for the next grouped frontend pass.

## Boundaries

- No statistical engines changed.
- No result schemas changed.
- No numerical fingerprints changed.
- R/Rscript remain validation-only.
- Private raw datasets and value-revealing screenshots remain outside repository evidence.
