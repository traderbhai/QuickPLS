# QuickPLS 2.8.0 Release Notes

QuickPLS 2.8.0 is a release handoff consistency milestone for the QuickPLS 2.x frontend program.

## Highlights

- Public README, installation, and source-build guidance now point to the current QuickPLS 2.x release workflow.
- The active milestone tracker records the current v2.8.0 gate and the latest artifact convention.
- Versioned desktop artifacts continue to use non-overwriting setup, portable executable, and checksum filenames.
- The v2 release handoff audit checks screenshot references, artifact guidance, current gate commands, stale version markers, encoding safety, and non-equivalence wording.

## Runtime And Scope

QuickPLS remains a free, proprietary, offline Windows desktop application. R, Python, lavaan, cSEM, SEMinR, and similar tools remain validation-only and are not runtime dependencies.

No statistical engines, formulas, result schemas, method validation, project archive format, validation tolerances, or numerical fingerprints changed in this milestone.
