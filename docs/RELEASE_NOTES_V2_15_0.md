# QuickPLS 2.15.0

QuickPLS 2.15.0 improves workflow and method guidance after the real-dataset triage pass.

## Highlights

- Data, Model, Setup, and the top command bar now make method availability and next actions clearer.
- Setup shows why the selected method is recommended, available, needs setup, blocked, or scoped.
- Method cards now carry exact next-action and missing-requirement metadata for validation.
- The top method selector remains conservative and points users to Setup for the full method catalog.
- R-squared labels are rendered as `R²`.

## Scope

This release is frontend/product-only. It does not change QuickPLS statistical engines, formulas, result schemas, project archives, validation tolerances, or numerical fingerprints.
