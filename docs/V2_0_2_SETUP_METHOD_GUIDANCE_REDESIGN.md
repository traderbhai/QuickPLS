# QuickPLS v2.0.2 Setup Method Guidance Redesign

## Summary

v2.0.2 rebuilds the Setup workspace around the QuickPLS 2.0 desktop design direction. The screen now explains the selected calculation first, shows readiness and scope checks, separates recommended methods from setup-dependent methods, and keeps method-specific fields in a selected-method sidecar.

This milestone is frontend/product-only. It does not change statistical engines, formulas, result schemas, project archive format, validation tolerances, or numerical fingerprints.

## Delivered Changes

- Added a selected calculation command panel with method reason, category, expected outputs, scope access, and run readiness.
- Moved readiness into a v2 panel with compact method status cards.
- Replaced the flat method list with a guided method browser:
  - recommended methods;
  - available after setup;
  - advanced diagnostics;
  - standalone/workflow analyses.
- Added a selected-method sidecar with requirement checks, exact next actions, and method-specific fields.
- Kept Basic/Expert setup modes, with advanced reproducibility and group/prediction controls under Expert.
- Preserved research presets and launch preview while making them visually consistent with the v2 shell.
- Fixed remaining `R²` display text in Setup fallback/output descriptions.
