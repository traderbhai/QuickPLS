# QuickPLS v2.21-v2.35 Native Desktop Redesign Program

Objective: make QuickPLS feel like native desktop research software, closer to SmartPLS, SPSS, and AMOS workbench conventions, without changing statistical engines or numerical outputs.

Program rules:

- Frontend/product only unless explicitly approved.
- SEM designer core behavior is preserved.
- New UI state is presentation-only and must not affect numerical fingerprints.
- Installer, portable exe, and checksums are built at release-candidate stage or when explicitly requested.

Completed foundations:

- v2.21.0: desktop shell and status feedback foundation.
- v2.22.0: menu, command registry, dialog, and native interaction base.

Open sequence:

- v2.23.0 Home and Project Manager.
- v2.24.0 Data Workbench Redesign.
- v2.25.0 Model Workbench Integration.
- v2.26.0 Method Setup and Applicability Center.
