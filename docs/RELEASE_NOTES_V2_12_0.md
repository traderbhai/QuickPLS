# QuickPLS 2.12.0

QuickPLS 2.12.0 adds the real dataset review protocol for launch-quality product feedback without storing private research data in the repository.

## Added

- Manual private-dataset review checklist for Data, Setup, Results, and Report.
- An anonymized issue-register template under `validation/templates/`.
- Static smoke and audit scripts for the v2.12 protocol gate.
- Updated active milestone tracker and development registry.

## Boundaries

- No statistical engines changed.
- No result schemas changed.
- No project archive format changed.
- No numerical fingerprints changed.
- Private datasets, private `.qpls` files, and value-revealing screenshots remain out of repository artifacts.
