# v1.7.6 Sample Projects And Guided Research Workflows

Adds a sample-project gallery and a guided Start from dataset flow covering import, quality inspection, prefix detection, construct creation, model arrangement, validation, running, checklist inspection, and report export.

The gallery exposes only complete bundled workflows. In the current source these are the corporate-reputation PLS workflow, a simple reflective PLS workflow, and a three-construct mediation workflow. The selected sample identity is sent to the native backend; the action must never silently replace it with another demo.

Additional method examples belong in the gallery only after their exact dataset, typed model and recipe, completed result, report/export surfaces, and save/reopen behavior are implemented and tested.
